날씨에 반응하는 컬러 요약과 배경 — v1.0.82

범위
- 기존 하늘 사진 4종을 재사용. 새로운 래스터 이미지나 동영상 다운로드는 없음.
- 첫 요약 카드와 페이지 뒤의 하늘은 컬러로, 시간별/주간/상세/설정 데이터는 모노크롬으로 유지.
- 사진은 장식이며 실제 수치·문구는 HTML, 아이콘은 SVG. 배경 효과는 읽기 도구와 포인터 조작에서 제외.

구현
- src/lib/weatherScene.ts: WMO 날씨 코드, 기상청 강수 관측, 현재 풍속/돌풍을 조합.
- src/components/WeatherFx.tsx: CSS 구름/빛/안개 + 제한된 캔버스 비/눈/별/별똥별/번개/바람/작은 잎.
- src/atmosphere.css: 페이지와 요약 화면의 레이어, 컬러 톤, 흰색 글자 대비, 반응형.
- 날씨별 8종(맑은 낮, 맑은 밤, 구름 조금, 흐림, 비, 눈, 안개, 뇌우)에 바람 4단계를 독립적으로 조합.
- 바람 단계는 시각적 연출 강도이며 기상청 특보 등급이 아님. 기상특보는 기존 공식 특보 배너를 유지.
- 실제 현재 풍속은 기상청 관측(m/s를 km/h로 변환)을 우선하고, 없으면 Open-Meteo current를 사용.
- 오래된 저장 데이터에 현재 풍속이 없으면 강풍을 추측하지 않음. 표시 수치는 '오늘 최대 바람'으로 명확히 구분.

안전·성능
- 전경/배경 캔버스별 최대 입자 44/72개, 비·눈·바람은 최대 24fps, 느린 효과는 12fps.
- 캔버스 픽셀 예산은 각 약 180만 픽셀. DPR 최대 1.5로 제한하고 큰 화면에서는 더 낮춤.
- document visibility, IntersectionObserver, prefers-reduced-motion 변경에 반응하고 이벤트/RAF/관찰자를 정리.
- 동작 줄이기에서는 정적인 사진을 유지. 수동 끄기 상태는 로컬 저장소에 저장.
- 번개는 11~19초 간격의 작은 선/국소 빛. 빠른 반복 섬광·전체 화면 흰색 플래시·소리 없음.

검증
- 단위 테스트: 날씨별 사진, 풍속/돌풍 단계, 실황 우선순위, 뇌우 보존, 입자 상한, 저장소 오류, 현재 풍속 요청 단위.
- Chrome 모바일 에뮬레이션 320/390/768/1280px 및 4K 캔버스 예산 확인.
- 날씨 8종을 통제된 테스트 데이터로 렌더링. 현재의 실제 날씨로 표시되는 테스트 설정은 배포하지 않음.
- 멈춤/재생, 저장 후 다시 열기, 동작 줄이기 실시간 변경, 숨긴 탭, 화면 밖 요약 효과 정지 확인.
- 1.3초 동안 비 효과는 전경/배경 각각 30회 그리기. 4K에서 배경 캔버스 약 180만 픽셀 이내.
- 실기기 Safari/WebView 점검이나 접근성 인증을 의미하지 않음.
