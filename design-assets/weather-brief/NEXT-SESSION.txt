만들 기능:
날씨 앱 최상단에 뉴스레터처럼 짧고 센스 있는 날씨 브리핑 카드가 한 장씩 계속 순환하는 배너를 구현해줘. 스크롤해도 배너는 화면 상단에 고정되어 따라와야 해. 기존 네이비 디자인과 자연스럽게 어울리는 낮은 높이의 배너로 만들어줘.

표시할 내용:
- 내일 일출: “내일 해는 {현지 일출 시각}에 떠요”처럼 간결한 문구.
- 오늘 일몰: “오늘 해는 {현지 일몰 시각}에 져요”처럼 표시하되 이미 지난 시각이면 시제와 내용을 자연스럽게 조정.
- 지금 vs 어제 같은 시각: wx.nowTemp - wx.yesterdaySameHour로 더 따뜻한지/쌀쌀한지 표시.
- 내일 vs 오늘: wx.tomorrow.tmax - wx.today.tmax로 내일 낮 기온 변화를 표시. 아침은 필요하면 tmin끼리 비교.
- 차이가 거의 없으면 “어제 이맘때와 비슷해요”처럼 표시하고, 비교 기준이 현재인지 낮 최고인지 명확히 해줘.
- 문구는 짧고 자연스럽게 다듬되 시간·온도·날씨 정보를 지어내지 말고, 없는 데이터의 카드는 건너뛰어줘.
- 선택 지역을 바꾸거나 데이터가 갱신되면 배너도 같은 지역의 최신 정보로 맞춰줘. 화면에 남은 다른 지역 데이터와 섞이지 않게 해줘.

구현 시 중요한 점:
- src/lib/weather.ts의 WeatherData.sun은 현재 오늘의 일출/일몰만 반환해. Open-Meteo 요청에는 이미 sunrise/sunset 배열이 있으므로 내일 일출을 반환하는 필드를 확장해줘. 현재 응답에서 daily[0]은 어제이고 daily.sunrise[2]가 내일이지만 최신 코드를 확인하고 적용해줘.
- 기존 캐시에는 새 필드가 없을 수 있어. 누락을 허용하고 시간대/날짜 경계도 선택한 지역의 현지 시각 기준으로 처리해줘. 값이 없으면 임의의 시각을 넣지 마.
- .shell에 overflow: hidden이 있어. 이 내부에 sticky만 붙여 놓으면 고정이 실패할 수 있으니 실제 스크롤 컨테이너를 확인해. .shell 바깥에 fixed 배너를 두고 배너 높이 및 safe-area-inset-top만큼 본문 공간을 확보하는 방식이 가능해.
- 배너가 제목·방문자 수·지역 선택이나 설정/공유 대화상자를 가리지 않게 해줘. 모바일 웹뷰, iOS/PWA 안전 영역, 작은 화면을 확인해줘.
- 모바일 높이 약 76~84px, 제목 한 줄과 보조 문구 한 줄을 시작점으로 잡고 실제 문구가 잘리지 않게 조정해줘.
- 풍경은 오른쪽, 문구는 왼쪽에 놓고 넓은 화면에서 이미지가 과하게 확대되지 않게 해줘. 자세한 배경 크기 권장값은 README에 있어.
- GitHub Pages 하위 경로 /Weather-forecasting/를 사용하므로 import.meta.env.BASE_URL을 반영해 이미지 URL을 구성해줘.
- 한 장씩 약 6초 간격으로 끝없이 순환하고 250~400ms 정도로 차분하게 전환해줘. 페이지 표시와 일시정지/다시재생 기능을 배너 높이에 맞게 작게 제공해줘.
- prefers-reduced-motion에서는 자동 전환을 기본 정지하고 수동 전환을 제공해줘. 사용자가 정지하면 이후에도 의도치 않게 다시 시작되지 않게 해줘.
- 탭이 숨겨졌을 때 자동 전환을 멈추고 타이머를 정리해줘. 접근성 안내가 6초마다 계속 강제 낭독되지 않게 해줘.
- 기존 어제 대비 기온, 방문자 수, 미세먼지, 지역 변경 등 기능을 보존해줘.
