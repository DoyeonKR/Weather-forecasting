모노크롬 날씨 저널 — v1.0.80
2026-10-27

기준: origin/main 67eb4b2, v1.0.79. 실제 모바일·데스크톱 화면을 확인한 뒤 구현.

화면
- 지금 날씨 / 항상 보이는 어제와의 차이 / 준비물 3칸
- 오늘의 흐름: 시간별 예보와 출퇴근 비교
- 내일과 이번 주: 같은 묶음 안에서 비교
- 날씨의 디테일: 같은 페이지에서 필요한 항목만 펼침, 상세 순서 저장 유지
- 레이더: 지도와 현재 위치 버튼은 그대로 노출
- 사진과 지도/레이더의 데이터 색은 유지. 전체 grayscale 필터는 사용하지 않음.
- 테마 토큰과 반응형 규칙은 src/journal.css. 기존 기능용 App.css 뒤에 적용.

에셋
- public/icons/journal/: 직접 작성한 모노크롬 SVG 날씨 8종과 방향 4종
- 기존 morning-sky.webp / night-sky.webp 재사용
- rain-sky.webp (43,668 bytes), snow-sky.webp (53,920 bytes): 내장 이미지 생성 도구로 제작
- 새 사진은 1440×480 WebP, quality 86, effort 6. 실제 프롬프트는 prompts.json.
- 사진은 장식이며 alt는 비움. 수치·날씨 설명·차트는 실제 데이터로 렌더링.
- 공유 이미지는 실제 수치를 캔버스로 그리며 모노크롬 팔레트를 사용.

검증
- npm run typecheck, npm run lint, npm test (72개), npm run build
- Chrome 실화면: 320 / 390 / 768 / 1280px. 본문 가로 넘침 없음.
- OS 다크 모드에서도 밝은 모노크롬 유지.
- 실제 부산 검색, 지역 전환 완료, 즐겨찾기 추가, 현재 위치로 복귀 확인.
- 상세 순서 변경 시 전체 섹션 키·고정 정보 보존; Enter로 상세 펼침 가능.
- 설정·공유 시트: 키보드 포커스 유지, Escape 닫기, 원래 버튼 복귀.
- 시간별 그래프 가로 넘기기, 레이더 전체화면/닫기, 지도 안의 위치 버튼 확인.
- 브리핑 6초 자동 순환, 스크롤 시 44px 축소 확인. 모션 줄이기에서는 자동 순환 중지.
- 공유 대체 화면의 1080×1350 이미지 생성 확인.
- 방문 수는 검증 중 24명으로 모의 처리하여 실제 통계에 테스트 방문을 더하지 않음.
- 이 점검은 데스크톱 Chrome의 모바일 화면 에뮬레이션이며, 실기기 Safari/WebView 검증은 아님.
